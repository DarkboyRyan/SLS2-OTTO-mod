# OTTO 角色 Mod

为《杀戮尖塔 2》新增可选角色 **OTTO**，当前版本 **v0.6.103**。
选人背景使用新提供的黑金 V5 队服海报：等比例完整放在右侧，左侧和底部使用深色渐变保证界面文字清晰。
战斗形象依据海报生成透明全身立绘，并使用 Godot AnimationPlayer 制作基础动作。小头像继续使用最初提供的照片。
已实现用户工作簿中的86张设计卡，并新增初始牌进阶版本“同事是恩人”，共87张设计卡，以及三位可见的动物园伙伴。本批补齐 OTTO-061 至 OTTO-086 共26张新卡，包含少女乐队、伙伴指挥与救命、自动出牌和先古牌 v5-otto。
初始配置为 91 血、91 金币、3 能量，5 张 OTTO 打击、5 张 OTTO 防御、1 张呼朋唤友；起始遗物为“棍亩”：每场战斗开始获得 1 层无实体，使用用户提供的原图。
选人介绍使用用户提供的“自称是英雄联盟的职业选手的神秘人……”文案，以两段显示；生命和金币配置只影响新对局，进行中的存档保持原数值。
在原版 Orobas 事件中选择初始遗物升级选项，可将棍亩替换为“老棍和棍亩”：每场战斗开始获得 2 层无实体，图标使用用户提供的双人原图。
OTTO 使用独立奖励卡池（20 普通、37 罕见、25 稀有，另有3基础、2先古），不会改动铁甲战士的卡池。打击、防御、肯德基、哈利路大旋风、其人之道、兄弟你动啊、帅！OTTO!、啊，哥我错了、你马卖皮、AUG、完美的头球马内、我砍，我再砍、牛魔、唢呐、吹唢呐，嘟嘟嘟、偶内的手、阿米诺手、尊尼获加、Q都能Q歪来、我觉得我是职业选手、WOC!冰！、奥利安费、B三狼、冲刺！冲刺！冲刺、呼朋唤友、v5-otto、吉吉国王、不存在之物、说的道理、说的道莉、腾杨天下、深海鱼、进击的国王，以及下方v0.6.6列出的七张牌使用用户提供的图片卡面，其他卡面暂借用相近原版卡图；音效、普通遗物奖励、药水和营火/商店等其他场景素材继续沿用原版。

## v0.6.99 音频稳定性与音量修正

实测游戏已把主音量平方应用到 Godot Master 总线，自定义录音不再重复乘主音量；播放器仅应用分类音量平方，并保留显式主音量静音保护。战斗语音另提高增益并限制播放器增益不超过 1。并发召唤语音按同时播放数量分配增益。移除播放时动态修改 Godot 总线和音频效果的代码，保留卡牌、古神状态、召唤和死亡语音的触发规则。

## v0.6.98 死亡表现

OTTO 真正死亡时播放提供的死亡录音一次，并播放落地回弹后保持横躺的动画。死亡录音不因战斗结束立即中断，受主音量和音效音量控制。复活时停止死亡录音并起身。

## v0.6.97 卡牌专属语音

鸡掰！、白银就是癌症晚期、猪逼吧、冲刺！冲刺！冲刺、韭菜盒子、哈利路大旋风在打出时播放对应录音一次。录音按当前战斗语音响度处理，受主音量和音效音量控制。古神状态下专属语音结束后继续随机古神语，同一次出牌的重复结算不重复触发语音。

## v0.6.96 同事是恩人

新增古老之牙专属进阶技能牌“同事是恩人”，通过 Orobas 的古老之牙将呼朋唤友替换获得，不加入普通奖励卡池，1 费，强化后 0 费。随机召唤一位未入狱伙伴，并让它立即行动 5 次。沿用现有召唤与动物园的羁绊规则，使用用户提供的三人卡面。

## v0.6.95 语音与界面调整

战斗语音再提高增益并限制峰值。独立语音总线限制羁绊三段并发的总峰值。动物园的羁绊成功召唤的伙伴语音同时播放；其余召唤保留队列。五张牌删去不可叠加说明；双人升级遗物图标用透明留白保持原比例。

## v0.6.94 卡牌描述精简

冲刺！冲刺！冲刺、偶内的手、阿米诺手的中英文描述删去重复基础数值，保留动态效果值、伙伴加成和连招条件；卡牌效果与升级数值不变。

## v0.6.93 战斗语音增益

六段古神语和三段召唤音在已统一响度的基础上提高 6 dB，并使用峰值限制避免爆音；选角背景音保持原音量。

## v0.6.92 音频响度统一

全部 10 段录音统一处理，统一至约 -16 LUFS，目标真峰值 -1.5 dBTP。保留游戏主音量、音效音量及音乐音量控制。

## v0.6.91 伙伴召唤音

炫狗、山泥若、火星包成功召唤时分别播放用户提供的录音。多人同时召唤时逐段排队播放，读档或视觉重建不重播；死亡或战斗结束时停止。跟随主音量和音效音量。

## v0.6.90 古神语音

打出古神牌时从六段用户录音中随机播放一段；古神状态中逐段随机播放，避免相邻重复。新的古神牌切换当前语音，退出形态、死亡或战斗结束时停止。跟随主音量和音效音量。

## v0.6.88 选角背景音

每次选择 OTTO 时播放一次用户录制的约 6 秒音频，结束后恢复菜单音乐。切换其他角色、关闭选角或开始对局时停止；随游戏主音量和音乐音量设置变化，并在播放期间压低原菜单音乐。资源为 `OTTO/audio/otto_select.ogg`。

## 编译和安装

环境：.NET SDK 9 或更高版本、MegaDot 4.5.1、已安装的游戏，以及游戏内启用的 BaseLib 3.4.7 或兼容版本。

```bash
./build.sh             # 生成 dist/OTTO 中的 DLL、PCK、JSON
./build.sh --install   # 生成后复制到本机游戏目录
```

安装后重新启动游戏，在“设置 → Mod 设置”中确认 BaseLib 和 OTTO 已启用。
打开单人模式的角色选择界面，即可选择带有自定义照片头像的 OTTO。
只改 C# 时可以执行 `dotnet build` 更新本地分发目录；要让游戏生效仍需安装并重启。
改头像、海报、战斗图片、场景或文本后必须重新运行完整构建脚本，以更新资源包。

- 无实体直接使用原版状态：玩家回合末不减少，敌方回合末减少 1 层。两层通常保护前两个敌方回合，后续玩家回合不会自动补层；下一场战斗重新给予。

- 吉吉国王已在v0.6.2改为指挥伙伴并积攒古神值。旧水果模型已在v0.6.7移除。
- B三狼的“目标”栏与效果文字不一致，按效果文字实现为随机三连击。
- 轮椅先加敏捷再给基础 6 格挡，所以该次格挡也享受新敏捷。冰与炫狗产生的固定格挡不吃敏捷加成。
- 职业选手每层使每张出牌获得 1 皮克斯，能力自身也计入；在牌效果开始前记数，避免漏算致命牌。战斗结束后每层皮克斯加 1 最大生命并按原版 GainMaxHp 回复等量生命。

## 战斗动作与后续修改

人物主体显示高度约 304 像素，原点位于鞋底中央。攻击使用逐帧姿势切换，其他动作使用立绘变换，尚未使用骨骼绑定。
`idle` 轻微伸缩模拟呼吸；`attack`/`heavyAttack` 抬手蓄力、向右伸拳、收拳；`cast`/`powerup` 抬升并闪暖金色；`hurt` 后仰闪红；`die` 倒地并停留；`revive` 起身回到待机。
出拳动作共 0.48 秒，在 0.15 秒切到完全伸拳帧，与角色的 `AttackAnimDelay` 同步。其他姿势的时间配置在 `PUNCH_TIMES`，播放顺序在 `PUNCH_FRAMES`。
图集使用左上、左下、右下三个姿势；右上姿势使用了另一只手蓄力，未用于最终动作。分区边界放在 y=780 的透明间隔，避免上排鞋底混入下排。
普通动作结束都自动接回 `idle`；受击、施放或死亡打断攻击时，也立即恢复基础贴图、脚底锚点和缩放，避免伸拳姿势残留。

要改动作，编辑 `tools/create_combat_scene.gd` 后运行：

```bash
# 先导入纹理，再根据脚底位置和关键帧生成场景，最后编译安装。
"/Users/ryanding/Applications/MegaDot.app/Contents/MacOS/Godot" --headless --editor --path . --import
"/Users/ryanding/Applications/MegaDot.app/Contents/MacOS/Godot" --headless --path . --script tools/create_combat_scene.gd
./build.sh --install
```

也可以直接在 MegaDot 的 AnimationPlayer 编辑场景；之后不要再运行生成工具，否则会用脚本中的配置覆盖手动调整。

## 后续扩展

所有生成的 C#、GDScript 和构建脚本都有中文注释；不支持注释的 JSON 在本文和美术清单中解释。
角色内部 ID `OTTO_CHARACTER` 用于存档，不应为了修改显示名称而更改。
后续新增卡牌继承 `OttoCard`，使用稳定的 `CustomID`，并补充中英文 `cards.json`。卡池会自动收录。
本版本通过 `CustomVisualPath` 声明战斗资源，并在 `CreateCustomVisuals` 中显式调用 BaseLib 工厂，将普通 Node2D 转换为游戏的 NCreatureVisuals；BaseLib 同时转发动作触发。
若需要更平滑的挥拳、转身或连续组合拳，可以继续补充过渡帧，或将头、躯干、上下臂和腿分层后制作骨骼动作。
当前复用原版模型配置，游戏或 BaseLib 更新后仍需重新编译和游戏内验证。

参考：[BaseLib](https://github.com/Alchyr/BaseLib-StS2)、[角色视觉场景文档](https://alchyr.github.io/BaseLib-Wiki/docs/scenes/creature-visuals.html)、[作者模板](https://github.com/Alchyr/ModTemplate-StS2)。
